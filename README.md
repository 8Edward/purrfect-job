# Вакансии из Telegram → career-ops

Скрипт читает твои чаты и каналы в Telegram (включая приватные) от твоего имени,
находит вакансии за последние 3 дня и добавляет их в `data/pipeline.md`.
Дальше их оценивает `/career-ops pipeline`. Скрипт только читает: ничего не
отправляет и не отмечает прочитанным.

## Установка (один раз, ~10 минут)

1. **Python.** Установи с https://www.python.org/downloads/ и на первом экране
   поставь галочку **Add python.exe to PATH**.
2. **Репозиторий.** Склонируй `8Edward/search-job` на комп (или скачай ZIP с GitHub)
   и переключись на ветку `ccr-c86bb8ee-qi5m2j`.
3. **Ключи Telegram.** Зайди на https://my.telegram.org → *API development tools* →
   создай приложение (название любое). Скопируй `api_id` и `api_hash`.
4. Дважды кликни **`telegram\setup.bat`**. Он установит библиотеки и создаст
   `telegram\config.yml`.
5. Открой `telegram\config.yml` в Блокноте и впиши `api_id` и `api_hash`.
   В `exclude` перечисли чаты, которые читать не надо (работа, семья).
6. Дважды кликни **`telegram\login.bat`**. Введи номер телефона (`+7...`) и код,
   который придёт в Telegram. Ничего не запишется: скрипт только покажет, что
   нашлось бы. Если находит мусор или что-то пропускает — правь слова в
   `keywords` в `config.yml` и запускай снова.
7. **Расписание.** Нажми Win, набери `PowerShell`, открой и выполни:
   ```
   powershell -ExecutionPolicy Bypass -File "ПУТЬ\search-job\telegram\schedule.ps1"
   ```
   Теперь сбор идёт каждый день в 09:00 и 20:00. Если комп был выключен, сбор
   запустится, когда его включишь.

## Каждый день

- Новые вакансии появляются в `data/pipeline.md` (строки `local:jds/tg-...`),
  полные тексты лежат в `jds/`.
- Оценка: открой Claude Code в папке репо и напиши `/career-ops pipeline`.
- Что делал сборщик: `data\tg-collect.log`.
- Запустить вручную: `telegram\run.bat`.

## Безопасность

`telegram\tg.session` — это **полный доступ к твоему аккаунту Telegram**. Никому
его не отправляй. В git он не попадает (как и `config.yml`). Если комп украли
или файл утёк: Telegram → Настройки → Устройства → завершить сессию.

## Как работает фильтр

Сообщение считается вакансией, если в нём есть слово «про вакансию»
(`вакансия`, `ищем`, `hiring`, `зарплата`…), слово «про роль» (`аналитик`,
`SQL`, `data`, `BI`…) и нет слов из `negative` (`#резюме`, `ищу работу`).
Совпадения с `tags` (part-time, contract, remote) добавляются пометкой в строку
пайплайна. Один и тот же пост из нескольких чатов попадает в пайплайн один раз.
